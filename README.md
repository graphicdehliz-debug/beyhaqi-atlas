# اطلس جغرافیایی تاریخ بیهقی — پیش‌نمایش (نسخه تاییدشده)

سازنده و پژوهشگر: فائزه فاضل — ناظر علمی: دکتر سلمان ساکت

## صفحات
- index.html — نقشه تمام‌صفحه (نقشه مرجع + نشان لوزی غزنه؛ کلیک = زوم و پنل کوتاه)
- ghazna.html — پرونده غزنه (۵ دسته تاییدشده)
- about.html — درباره پژوهش (بدون بخش «روش کار»، به تصمیم فائزه)
- sources.html — منابع

## هویت بصری
کرم #F7F0DF / زرشکی #701E2A / سرمه‌ای #1C2B4A / طلایی کدر #B08D3C فقط برای تذهیب.
نقش هشت‌پر آجرکاری غزنوی، قاب دولایه نسخه خطی، عنوان نستعلیق، متن وزیرمتن، شمسه کنار عنوان.

## اجرا

Antigravity / AI Studio: همین ساختار پوشه را نگه دار (index.html در ریشه، css/js/assets کنارش).

# اطلس جغرافیایی تاریخ بیهقی (Beyhaqi Geographical Atlas)

پروژه پژوهشی در حوزه علوم انسانی دیجیتال (Digital Humanities) برای بررسی پیوند میان متن «تاریخ بیهقی»، جغرافیای تاریخی، جغرافیای معاصر و میراث مادی.

**سازنده و پژوهشگر:** فائزه فاضل (دانشگاه فردوسی مشهد)  
**ناظر علمی:** دکتر سلمان ساکت (دانشگاه فردوسی مشهد)

## اولویت نسخه فعلی
تمرکز انحصاری بر **غزنه در عصر بیهقی** با داده‌های تأییدشده، تفکیک شفاف نوع شواهد و وضعیت اعتبار داده‌ها، و ساختار داده‌ای مقیاس‌پذیر برای افزودن شهرهای آینده بدون بازنویسی کد.

## ساختار فایل‌ها
- `index.html` — نقشه تعاملی تمام‌صفحه، سایدبار تب‌دار (پرونده، لایه‌ها، راهنما) و خط زمانی تفکیک‌شده (۹۷۷ تا ۱۲۲۱ میلادی)
- `ghazna.html` — پرونده پژوهشی غزنه شامل شناسنامه قابل استناد، نقشه اختصاصی، جایگاه در تاریخ بیهقی، خط زمانی با فیلتر دوره‌ای، ۶ شخصیت مرتبط، ملاحظات پژوهشی و منابع
- `about.html` — معرفی پژوهش و روش‌شناسی اعتبارسنجی داده‌ها
- `sources.html` — منابع پایه پژوهش
- `css/style.css` — هویت بصری یکپارچه (کرم کاغذی، زرشکی، سرمه‌ای، طلایی کدر، نقش هشت‌پر غزنوی، قاب دولایه)
- `js/data.js` — منبع واحد داده‌های پژوهشی تأییدشده (مقیاس‌پذیر برای شهرهای آینده)
- `js/map.js` — منطق نقشه صفحه اصلی، تفکیک نقشه پایه از لایه‌های پژوهشی و نوار زمان
- `js/place.js` — رندر پویای صفحه پرونده شهر و نقشه درون‌متنی
- `assets/reference-map-cropped.jpg` و `assets/reference-map.jpg` — نقشه مرجع «نام جاهای تاریخ بیهقی» (سیدی–یاحقی)

## اجرای محلی
1. پوشه پروژه را در VS Code باز کنید.
2. روی `index.html` راست‌کلیک کرده و گزینه `Open with Live Server` را بزنید.
